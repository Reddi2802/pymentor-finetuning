# PyMentor Dataset

The raw dataset contains chat-style JSONL records. Run `python src/prepare_dataset.py` to validate and create train, validation, and held-out test splits.

The included 20 examples are only a pipeline smoke-test set. Before final submission, expand them to 400-800 varied, reviewed examples. Never add test-set questions or close paraphrases to training. Document data sources and AI assistance in the root README.
